# OVERLORD REIGN Dark Tower Restoration Decisions

Status: PROJECT DECISION MIRROR

Date: 2026-09-13

Authority: records explicit OVERLORD REIGN decisions governing the Dark Tower restoration questline and the boundary between Tower-owned restoration work and independent system questlines.

This file exists specifically to prevent the Quest implementation from splitting Tower-owned systems into unrelated standalone questlines or, conversely, swallowing independent progression into Tower restoration.

## 1. Overarching Tower Restoration questline

Status: CANON DESIGN / PLANNED IMPLEMENTATION

The Dark Tower uses one overarching Tower Restoration questline.

Individual rooms, facilities, personnel functions, and systems may form branches or milestones within that questline, but they are all understood as parts of restoring one functioning Dark Tower rather than as unrelated mod tutorials.

The Tower restoration arc may remain semi-open where prerequisite logic allows. It does not need to force one strict room-by-room order unless a system genuinely depends on another.

## 2. Restoration means activation and installation, not rubble repair

Status: CANON WORLD / DESIGN RULE

The current Dark Tower manifested as a purpose-built architectural shell.

Its rooms already have intended functions. Restoration therefore means installing, furnishing, activating, reconnecting, or making those functions operational.

It does not mean treating the new Tower as an ordinary ruined fortress whose walls and floors must be repaired from historical battle damage.

This preserves the existing opening canon established in `reference/15_REIGN_QUEST_LORE_DECISIONS.md`.

## 3. Room restoration versus system mastery

Status: CANON QUEST-ARCHITECTURE RULE

When a gameplay system has a dedicated Tower room or facility, the boundary is:

- INITIAL ROOM / FACILITY RESTORATION belongs to the overarching Tower Restoration questline;
- DEEPER SYSTEM MASTERY belongs to that system's own progression or dedicated questline where one exists.

Tower Restoration should therefore establish that the Overlord has acquired, installed, activated, or made a facility usable.

It should not absorb an entire magic, crafting, smithing, or progression system merely because the Tower contains a room for it.

Example already established:

- Hot Iron's forge-room installation belongs to Tower Restoration;
- further Hot Iron use and progression does not become a separate Tower-restoration chain merely because the forge is housed in the Tower.

## 4. Core Tower restoration milestones

Status: CANON DESIGN

The following established Tower functions should each receive an explicit restoration, activation, or operational milestone where technically appropriate:

- Throne room;
- Forge;
- Minion infrastructure;
- Gates;
- Treasury.

These milestones do not all need equal quest length.

A room or system may require only a short activation objective if that is all the underlying gameplay supports.

The Quest Maker must not manufacture disproportionate progression simply to make every Tower function equally large.

## 5. Selected magical Tower rooms

Status: CANON DESIGN

Not every major magic system receives a dedicated Tower room.

The selected magical functions that do receive dedicated Tower-space treatment are:

- Alchemy;
- Theurgy;
- Gluttony;
- spell study / spell making;
- Eidolon.

Their precise implementation mapping follows the established magic-system documentation elsewhere in the project. This file does not redefine those systems.

The physical activation of each selected room belongs to Tower Restoration.

Their deeper magical progression remains outside Tower Restoration and belongs to their own established magic progression or questline.

Biomancy is not automatically granted a dedicated Tower restoration room by this decision.

No additional magic system should be given a Tower room merely because it is a major mod unless a later explicit Tower-design decision adds one.

## 6. Quaver's band remains separate

Status: CANON DESIGN

Quaver's Immersive Melodies band questline remains a separate small Tower-personnel arc.

Its outcome improves Tower court life, atmosphere, and personnel presence, but it is not required for formal completion of Tower Restoration.

This prevents optional court-life content from becoming a mandatory infrastructure gate.

## 7. Treasury restoration versus treasury progression

Status: CANON DESIGN

Tower Restoration includes restoring or activating the Treasury room itself.

It does not create a separate mandatory treasury-progression grind.

The player should not be required to accumulate arbitrary gold thresholds merely to complete room tiers.

Later accumulated wealth, treasure, trophies, or visual signs of riches may be reflected where technically practical, but that is post-restoration world expression rather than the Treasury restoration questline itself.

## 8. Minion Hive and type handling

Status: CANON DESIGN / IMPLEMENTATION CONDITIONAL

The Tower quest system must not invent separate Hive-restoration chains for Minion types that are not actually implemented in gameplay.

If traditional Brown, Red, Green, and Blue Minion-type unlocks are successfully integrated into Minions Remastered or another compatible implementation, the quest system should acknowledge those actual unlocks as they occur.

If those tribe-specific gameplay unlocks are not implemented, there is no need to create fictional Tower-restoration quests for four separate Hives merely to imitate the original games.

The in-universe existence of the four traditional tribes remains canon independently of whether four separately playable gameplay types are available.

Minion-related Tower restoration must therefore follow the actual implemented Minion capability set available when the questmod is built.

## 9. Completion boundary

Status: CANON DESIGN

Tower Restoration is complete when the Tower's core operational facilities have been restored or activated to the extent required for a functioning seat of Overlord rule.

Completion does not require:

- every optional room;
- every personnel comfort;
- every trophy or decorative object;
- every later specialist facility;
- every magical system to be fully mastered;
- every Minion-related possibility to be unlocked if it does not exist in the installed implementation;
- every architectural portion of the physical Minecraft build to be finished.

Optional Tower content may continue indefinitely after formal restoration completion.

This follows the broader campaign rule that the Dark Tower is an evolving Minecraft base and seat of rule, not a completionist checklist that can soft-lock the campaign.

## 10. Quest Maker protection rule

Status: IMPLEMENTATION GOVERNANCE

Before assigning a standalone questline to a mod or system that has a dedicated Dark Tower room, the Quest Maker must first check this document.

If the proposed content is about installing, activating, furnishing, or making that Tower facility operational, it belongs to Tower Restoration.

If the proposed content is about mastering, exploring, advancing, specializing in, or completing the broader system after the room is operational, it may belong to that system's own questline or native progression.

Do not split a Tower-owned restoration milestone into a standalone mod questline solely because the underlying mod has enough content to support one.

Conversely, do not force an entire mod progression into Tower Restoration solely because one room houses part of that system.

The correct boundary is physical / functional Tower activation versus deeper system progression.
